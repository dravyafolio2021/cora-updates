# Visual Direction - Agency Client Onboarding Playbook

## Core creative idea

**Chaos -> clarity inside a real agency.**

The visual system should immediately feel relatable to an agency founder/account manager: client messages, missing access, assets, approvals and scope questions on one side; a calm structured onboarding system on the other.

Do not use a monochrome editorial card as the primary thumbnail.

## Cover / hero image

Preferred composition:

- Natural modern agency workspace, not a staged corporate boardroom.
- One believable agency operator working at a laptop.
- Left side: scattered messages, missing access, brand assets, revision notes, unclear scope, multiple tools.
- Right side: clean onboarding checklist, access tracker, kickoff agenda, scope sheet and 30-day roadmap.
- Visual transition from chaos to a clear system.
- Warm natural lighting, human expression, premium but achievable environment.
- Cora branding remains subtle.

### Cover copy

**The Agency Client Onboarding Playbook**

A practical system to turn signed proposals into organized, confident client delivery.

Small supporting labels:
- 8 practical chapters
- ready-to-use templates
- real agency workflows
- PDF onboarding pack

## In-guide visual system

### Graphic 1 - Sales-to-delivery handoff

Show:

Sales context -> Engagement brief -> Delivery team -> First milestone

Under Sales context:
- why client bought
- promises made
- definition of success
- risks / dependencies

Goal: visually explain that onboarding transfers context, not just form fields.

### Graphic 2 - Scope change decision tree

Client request -> classify:

- Clarification -> do it
- Revision -> apply revision rule
- Substitution -> confirm trade-off
- Additional scope -> Replace / Extend / Add

Goal: turn scope management into a simple decision flow.

### Graphic 3 - Access collection hierarchy

1. Delegated collaborator access
2. Role-based access
3. Shared credential only if unavoidable

Side callout:

**Request the minimum access needed for the work.**

### Graphic 4 - 35-minute kickoff map

0-5: Why now
5-12: Scope + responsibilities
12-20: Information + access
20-27: Communication + approvals
27-33: First milestone
33-35: Actions + owners + dates

### Graphic 5 - 30-day onboarding roadmap

Day 0 -> Days 1-3 -> Days 2-5 -> Week 1 -> Week 2 -> Week 3 -> Week 4

Use a horizontal roadmap on desktop and vertical stack on mobile.
